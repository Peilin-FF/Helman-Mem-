# Requirements for the Qwen3.5 center models (Qwen3.5-4B / 9B).
# Qwen3.5 uses the `qwen3_5` architecture (hybrid linear-attention), which transformers
# 4.56 does NOT recognize. It needs transformers 5.10.2 + huggingface-hub 1.18 (the
# tf5_overlay env). Train/eval go through the plain HF forward path, NOT vLLM, so the
# vLLM block from the Qwen3 requirements is intentionally omitted (vLLM 0.8.5 pins an
# older transformers and would conflict).
#
# In this repo the overlay is provided via a PYTHONPATH prefix
# (PYTHONPATH=/workspace/cloud_android/fengpeilin/tf5_overlay:.) on top of the Qwen3 env,
# so only transformers + huggingface-hub differ; everything else matches requirements_qwen3.txt.
# This file is the standalone equivalent for a clean install.
#
#   pip install -r requirements_qwen3.5.txt
#
# Note: Qwen3.5 linear-attention runs on a slow torch fallback unless the optional fast
# kernels (flash-linear-attention + causal-conv1d) are installed; they are not required.
