1. What was asked, what was cleared

Target: a central model that natively stores, updates and uses a memory of peer reliability, whose accuracy rises with the number of stream steps on the training, in-distribution and OOD streams and rises during training, with improvements explained mathematically and without memorising the traits of the training peers.

Cleared first: the posterior-memory and whitened-memory modules with their quadratic read-out, the steerer and aggregator trainers that steered a frozen judge with a scalar, six m_route_* diagnostics, and every launch_*.sh scheduler (they were respawning jobs on the shared machine). Kept as baselines: the published symmetric_memory.py, train_symmetric_memory.py and evaluate_sigma.py. All of it is recoverable from ~/.rproj-local-trash/sigma-mem-abandoned-20260904 and the server's git history.

2. The memory

Every event gives a question, three peer answers and, after the decision, the verified correctness of every peer. The frozen center model turns the question and each candidate answer into hidden states; an unsupervised PCA of those states (fitted once on training features, no labels) is the address ψ. Peer competence is modelled as a linear function of the address with Gaussian noise, and the memory is its exact posterior:

Λ_t = λI + Σ_{τ≤t} ψ_τ ψ_τᵀ b_t = Σ_{τ≤t} s_τ ψ_τ (s = ±1 correctness; both sums, hence order-invariant) μ(ψ) = ψᵀ Λ⁻¹ b v(ψ) = ψᵀ Λ⁻¹ ψ P(correct | history) = Φ( μ / √(1 + v) ) write: k = Pψ / (1 + ψᵀPψ), P ← P − k ψᵀP, m ← m + k (s − mᵀψ) (Sherman–Morrison = delta rule with the Kalman gain)

The last line is the point of contact with DeltaNet, Gated DeltaNet and Kimi's KDA: they apply S ← S(αI − βkkᵀ) + βvkᵀ, one gradient step of the same least-squares objective with a fixed or gated rate. The Kalman memory is the closed-form optimum with a direction-dependent step, large where evidence is scarce and small where it is abundant; a forgetting factor ρ reproduces the gated decay when a stream is non-stationary. The address design used everywhere below (qc) stacks a peer-blocked question part with a shared candidate part, so one linear model holds both “who is reliable on questions like this” and “does this answer look right”.

Three properties predict the curves: the state is order-invariant, so fixed and shuffled orders end in the same posterior; the online-ridge regret is O(d log T), so the average excess loss decays like d log T / T and the curve rises fast and then flattens; and the probit predictive shrinks uncertain reads to 1/2, so a cold region cannot dominate a decision.

4. Learning the address for online learnability

The Kalman recursion is differentiable, so the projection from frozen features to the address can be trained on cold-start episodes of the training stream with the same online selection loss, gradients flowing through the whole recursion. This shapes the address for how fast the memory learns, not for offline classification; it is the slow-weights / fast-weights split of DeltaNet, TTT and Mesa layers with the fast weights solved in closed form.

Reversible addresses

The Kalman state is already a lossless summary (a sufficient statistic with a closed-form downdate), and its read-out through Λ⁻¹ is the invertible change of basis that separates overlapping questions (raw squared cosine 0.5, whitened 0.002). The only lossy step is the PCA address, so two reversible learned maps were trained with the same online-learnability objective: an orthonormal map (norm-preserving, exactly decodable back into hidden-state space) and an invertible affine-coupling flow on the PCA coordinates (a bijection with a closed-form inverse, so nonlinearly encoded structure can become linear for the memory without losing anything).

5. Training the judge to read the memory

The judge (Qwen3-4B with rank-16 LoRA adapters) scores each candidate as z_p(θ; memory evidence in the residual stream) + κ·ℓ_p: the memory's log-odds enter additively as the Bayes prior and, through the paper's steering interface, into the upper decoder layers so the judge can weigh the reliabilities of all candidates while reading them. The loss is the negative log-probability that the selected candidate is correct, summed along cold-start episodes with the candidate slots randomly permuted per event. Because the memory's term is present during training, the gradient carries only what the memory cannot explain: the judge is trained as the residual verifier.

Verdict on the interaction. With frozen adapters, in-domain the trained judge subsumes the memory (what the memory knows there is also learnable from the answers' content and style) and OOD the memory subsumes the judge (its verification skill is domain-specific, and letting the memory learn online how much to trust it changes nothing). Both read the same frozen representation, and the memory extracts its linear, transferable part online.

What moves the OOD curve past the memory's plateau is letting the judge keep learning from the same feedback: one optimiser step every two events on its own selection loss. The OOD accuracy then rises across the stream (62.5% in the first half, 63.6% in the second, 64% in the last tenths) instead of flattening at 62%; a second shuffle seed gives 63.35% (62.5 → 64.2), and Qwen3.5-4B 63.8% (63.3 → 64.4; memory alone 62.3%, frozen judge 59.5%).

The control settles what the memory is. The judge trained without any memory, adapting online with the memory off, reaches 63.08% with the same rise. On top of an adapting judge the explicit Kalman state adds nothing: the LoRA weights updated from feedback are themselves a memory, the slow gradient-updated one, and over thousands of events they absorb what the closed-form state knows. The Kalman memory stays the cheap component, exact after a handful of events with no backward pass and calibrated evidence counts; the adapting weights are the component that keeps rising. Both are the same objective at two timescales.

6. Making the judge need the memory: reliability-shift training

Section 5 showed the memory being ignored by a trained judge. The reason is the training distribution: with three fixed peers on a stationary stream, reliability is a function of answer style and question type, the adapters learn that function directly, and nothing is left for the memory to supply. The remedy is the usual meta-learning condition: what is predictable from the weights is never read from the state, so make it unpredictable. Every training episode (1,024 events, cold-start memory) draws a hidden corruption rate per peer from {0, 0, 0.3, 0.6, 0.9} and corrupts that peer's correct answers at that rate while keeping its style (math: its own solution with the final number changed; reading and code: its own response to another question). Within an episode, reliability can then only be read from the feedback the memory accumulates.

The judge still does not need the memory, and the numbers say why. Even under a 90% corruption of the reading-comprehension expert, the trained judges score 63 with or without the memory, above the memory's own 61: they verify the corruptions from content, exactly as they verify most natural errors on these benchmarks. Reliability information is decisive only where verification fails — the frozen judge gains 11 points in-domain and 6 OOD from the memory, the trained judge with frozen adapters gains 2.6 OOD — and it is redundant for a trained verifier on in-domain data. That is a property of this task family (three checkable peers), not a defect of the memory: "who is usually right" adds little once "is this right" can be answered. Writing the memory into the prompt as text, the channel the model reads most natively, is read (the frozen judge's own score rises from 57.3 to 64.7) and gives the best shifted-stream judge (63.6), yet the gain over the no-memory judge stays within half a point.

7. Where the memory does beat both baselines: the central model answers, and votes with the peers

Selection is capped by the per-event oracle (69.6 OOD, 75.2 in-distribution, 82.6 train). If the central model writes its own answer, that answer becomes a fourth candidate, and the memory can track its reliability exactly as it tracks the peers'. The decision is then the reliability-weighted vote over the four answers (the Nitzan–Paroush rule with online-learned weights): the model's own reasoning is untouched, and a peer overrides it only when the memory says that peer is more reliable on questions like this one and the peers agree.

Fine-tuning on peer solutions teaches copying and halves the model's reasoning (math 89.5 → 74.9; output length 364 → 173 characters; a wrong peer is copied five times as often; on code, when every peer fails the fine-tuned models score 0% against 8% frozen). Self-distilled targets recover math (84.8) but not the total. The vote does what the fine-tunes were meant to learn: on the training stream it rises from 77% to 81% across the stream, takes reading from the reliable peer (78.5 vs 55.4 alone), keeps the model's own math (92.1), and lifts code to 38.2, above the best peer selection (30.7) and above the peers-only oracle (41.2 is the bound). It is the one configuration that beats both the frozen model and every model trained without the memory, and its trainable part is the central model's own solving, whose improvements propagate through the vote.
